# ServiceNow-Based Employee Laptop Request Application


## About the Project

The **ServiceNow-Based Employee Laptop Request Application** automates employee laptop requests, manager approvals, status updates, and email notifications using **ServiceNow**.


## Features

- Centralized request management
- Employee laptop request form
- Manager approval workflow
- Automatic status updates
- Approval and rejection handling
- Email notifications
- Reduced manual intervention


## Technologies Used

### Platform

- **ServiceNow**

### User Interface

- **Service Portal**
- **Service Catalog**

### Application Components

- **Flow Designer**
- **Catalog Variables**
- **Record Producer**

### Notifications

- **ServiceNow Email Notifications**


## Project Workflow

**Employee Enters laptop requirement details**  
↓  
**Laptop request record created**  
↓  
**Manager approval triggered**  
↓  
**Manager Approves or Rejects the Request**  
↓  
**Status updated automatically**  
↓  
**Email notification sent**


## Implementation

1. Create the Laptop Request application/form.
2. Add the required fields and catalog variables.
3. Configure the Record Producer to create the request record.
4. Design the approval process using Flow Designer.
5. Configure the manager as the approver.
6. Define separate actions for Approved and Rejected requests.
7. Configure automatic status/state updates.
8. Create email notifications for important request events.
9. Test the complete request lifecycle using different user roles.
